How it works

The launcher opens about:blank, writes a page into it with a fullscreen iframe, and sets the title and icon. If the browser blocks the popup, allow popups for this site and press the button again. The downloaded launcher file does the same thing from your own file, which helps when the site itself is filtered. data: URLs from Cloak Studio work here because the iframe, not the tab, carries them.

Convert between HTML pages and SVG files. HTML to SVG wraps a page into an SVG that runs it anywhere an SVG loads. SVG to HTML turns an SVG file back into a plain HTML page you can edit and host.

Convert

Loading a file also sets the direction for you (html in, svg out or the reverse).

How it works

HTML to SVG percent-encodes the page into a CDATA script inside the SVG and rebuilds it in a fullscreen iframe at run time, the same engine as Cloak Studio's SVG mode. SVG to HTML inlines the SVG into a plain HTML page. Inline SVG runs its scripts, so cloak SVGs keep working after conversion.
