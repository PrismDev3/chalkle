# Cobalt integration

Cobalt (cobalt.tools) is a free, open source media downloader. It supports
public links from TikTok (watermark-free), Pinterest, X, Instagram and more.

## What ships in Chalkle

- **Apps/Tools entry only.** There is no Cobalt tab, no embedded page and no
  copied source. Launching the card opens https://cobalt.tools/ in a new tab.
- A flat cobalt-blue download-arrow icon drawn to match the theme (flat fill,
  thick strokes, no gradients).
- Category: Downloader.

## Why not embed or fork it

Cobalt's web app is licensed CC-BY-NC-SA-4.0 (non-commercial). Chalkle runs
AdSense, so copying its frontend or embedding its UI in this ad-supported
product would violate the license. Linking out to the official instance is
safe and needs no attribution banner, but the credit below is kept anyway.

Based on Cobalt by imput (https://cobalt.tools), licensed CC-BY-NC-SA-4.0.
Watermark-free TikTok downloads depend on Cobalt's backend support per
platform and can change without notice.
