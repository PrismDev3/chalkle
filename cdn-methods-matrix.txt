notes
- jsdelivr: main jsDelivr endpoint, free for any public repo
- jsdelivr-default-ref: same cache, ref left out of the path
- jsdelivr-fastly: separate hostname - useful when the main one is filtered
- jsdelivr-combine: append ,gh/other/repo@ref/file to bundle several files into one request
- jsdelivr-min: jsDelivr minifies on the fly - only works for browser-safe JS
- statically-gl: install: git remote add gl git@gitlab.com:PrismDev3/<repo>.git && git push gl main
- statically-bb: install: git remote add bb git@bitbucket.org:PrismDev3/<repo>.git && git push bb main
- githack: the original GitHack - serves HTML as text/html
- rawgithack: no caching - live the second you push
- rawcdn-githack: cached copy, best for hot files
- github-raw: text/plain for HTML - good for fetch(), not for direct open
- gitcdnlink-repo: serves HTML as text/html
- esmsh-gh: serves SVG/HTML as real image/svg+xml and text/html; JS must be a valid ES module
- ghpages: live for PrismDev3/chalkle; an SVG committed to that repo would show up at prismdev3.github.io/chalkle/learn-1.svg
- unpkg: install: npm publish --access public
- jsdelivr-npm: install: npm publish --access public
- jsdelivr-esm: install: npm publish --access public
- esmrun: install: npm publish --access public
- esmsh-npm: install: npm publish --access public
- jspm: install: npm publish --access public
- gitlab-pages: install: mirror the repo to gitlab.com + a .gitlab-ci.yml with a `pages:` job
- codeberg-pages: install: mirror the repo to codeberg.org - Codeberg Pages serves the `pages` branch
- cdnjs: install: popular libraries only - PR against cdnjs/cdnjs packages/<name>.json
- google: install: curated set (jQuery, Angular, React, ...) - no self-publish path
- microsoft: install: legacy frozen list - jQuery, ASP.NET Ajax, Bootstrap, Modernizr only
- statically-root: 404s - the working host is cdn.statically.io
