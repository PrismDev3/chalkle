# Cobalt integration

Chalkle links to a self-hosted Cobalt instance through the Apps/Tools tab and the More tabs menu.

Cobalt is licensed under AGPL-3.0 for the applicable server code and CC-BY-NC-SA-4.0 for the web package. The upstream source and license are preserved in the source directory used to run the instance.

Cobalt only processes public URLs supported by the instance. Users are responsible for the content they submit and download.
