CDN Methods

One learn SVG, one JS file and one HTML page pushed through every free CDN-style service that answers. jsDelivr (9 endpoints: Cloudflare + Fastly, Gcore, Quantil, TestingCF, OriginFastly, BunnyCDN, /combine/ and .min.js), StaticDelivr, GitHack, raw.githack, raw.githubusercontent, gitcdn.link, ghfast / gh.jasonzeng proxies, esm.sh/gh and GitHub Pages.

Content-type gotcha: jsDelivr, StaticDelivr and raw.githubusercontent hand .html back as text/plain, so open games through GitHack, raw.githack, gitcdn.link, esm.sh/gh or GitHub Pages.
GitHub Pages + SVG: Pages is only enabled on the chalkle repo, so SVG links there start resolving the moment an SVG is committed to it; the svgbulk / chalkle-auto repos have no Pages.
