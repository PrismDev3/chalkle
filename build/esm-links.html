ESM Links

esm.sh serves npm packages and GitHub repos straight from a URL, no install or build step. Every link below is a working esm.sh URL.
3,938 links
Playable: npm packages that ship a real HTML page (games, demos, tools) - opens straight from esm.sh, like the burgerland pattern.
Chalkle mirrors: the site's own SVG mirrors and tools re-hosted through esm.sh/gh - SVGs get through filters that block other files.
Import URLs: paste into a <script type="module"> or import map - import x from "https://esm.sh/pkg@ver", zero install.
Icons are inline SVG data URIs so they never make a network request that a filter could block. 
<script type="importmap">
{
  "imports": {
    "react": "https://esm.sh/react@19.2.0",
    "react-dom/": "https://esm.sh/react-dom@19.2.0/"
  }
}
</script>
<script type="module">
  import React from "react";
</script>
